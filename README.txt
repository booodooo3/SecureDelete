Secure Delete - User Guide & System Requirements
==================================================

[English Section]

About the Program:
Secure Delete is a tool designed to permanently erase files from your computer. Unlike standard deletion, this program overwrites the file content multiple times with random data, making recovery impossible.

System Requirements:
- Operating System: Windows 7, 8, 10, 11
- Processor: 1 GHz or faster
- RAM: 512 MB or more
- Disk Space: 10 MB for the program
- Permissions: Administrator privileges may be required for deleting certain system or protected files.

How to Use:
1. Run the "SecureDelete.exe" file.
2. Select Interface Language:
   - Use the dropdown menu at the top to switch between "English" and "العربية".
3. Select a File:
   - Click the "Select File to Delete" button.
   - Browse and choose the file you wish to destroy.
4. Delete:
   - Click the "Start Secure Deletion" button.
   - A progress bar will show the deletion status.
   - Wait for the "Success" message indicating the file has been permanently removed.

Warning:
- Files deleted with this program CANNOT be recovered. Use with caution.

الحذف الآمن - دليل المستخدم ومتطلبات التشغيل
==================================================

[القسم العربي]

عن البرنامج:
برنامج "الحذف الآمن" هو أداة مصممة لمسح الملفات نهائيًا من جهاز الكمبيوتر الخاص بك. بخلاف الحذف العادي، يقوم هذا البرنامج بالكتابة فوق محتوى الملف عدة مرات ببيانات عشوائية، مما يجعل استرجاع الملف مستحيلًا.

متطلبات التشغيل:
- نظام التشغيل: ويندوز 7، 8، 10، 11
- المعالج: 1 جيجاهرتز أو أسرع
- الذاكرة العشوائية (RAM): 512 ميجابايت أو أكثر
- مساحة القرص: 10 ميجابايت للبرنامج
- الصلاحيات: قد يتطلب تشغيل البرنامج كمسؤول (Administrator) لحذف بعض الملفات المحمية.

طريقة العمل على البرنامج:
1. قم بتشغيل الملف "SecureDelete.exe".
2. اختيار لغة الواجهة:
   - استخدم القائمة المنسدلة في الأعلى للتبديل بين "English" و "العربية".
3. اختيار الملف:
   - اضغط على زر "اختر ملف للحذف" (أو Select File to Delete).
   - تصفح جهازك واختر الملف الذي تريد تدميره.
4. الحذف:
   - اضغط على زر "بدء الحذف الآمن" (أو Start Secure Deletion).
   - سيظهر شريط تقدم يوضح حالة الحذف.
   - انتظر حتى تظهر رسالة "تم بنجاح" التي تؤكد حذف الملف نهائيًا.

تحذير:
- الملفات المحذوفة بهذا البرنامج لا يمكن استرجاعها أبدًا. يرجى استخدامه بحذر.
